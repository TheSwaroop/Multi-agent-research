# Multi-Agent Research Workflow

## Overview
An AI-powered multi-agent research workflow built using Dify.

## Workflow Architecture
1. **Research Topic:** Receives the research topic from the user.
2. **Agent Researcher:** Collects relevant information.
3. **Agent Analyst:** Analyzes the research findings.
4. **Agent Report Writer:** Generates a structured report.
5. **Output:** Displays the final generated report.

## Technologies Used
- Dify
- Large Language Models (LLMs)
- Multi-agent AI workflow orchestration

## How It Works
The user provides a research topic. The workflow passes it through specialized AI agents for research, analysis, and report writing, then returns the final output.

## Note
Model access and API credentials may need to be configured separately when importing the workflow.
